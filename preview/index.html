Windows 7 Aero Explorer 1.0.0

FTP, done properly

  • Address-bar native. Type ftp://user:pass@host:21/path and press Enter.
  • Saved sites. The FTP Connection Manager (Ctrl+K) keeps bookmarks with obfuscated passwords in %APPDATA%\AeroExplorer\ftp_sites.ini.
  • Real transfers. Streaming WinINet uploads and downloads on a worker thread with live progress painted into the address bar — the UI never freezes.
  • Folder operations. Create, rename and recursively delete remote folders; recursively download a whole tree.
  • Drag & drop. Drop files from Windows Explorer onto a remote folder to upload them.
  • Passive mode & FTPS. Works behind NAT/firewalls; optional explicit TLS.
